# BuildForward – Civil Engineering

A student-created website introducing civil engineering and its impact on everyday life.

## Pages
- `index.html` – homepage
- `about.html` – purpose and approach
- `projects.html` – structural engineering, transportation, and seismic design
- `contact.html` – contact information and learning topics

## Stylesheets
- `reset.css` – browser style reset
- `hero.css` – shared layout, navigation, page styles, and responsive design

## Images
- `images/civil-engineering-hero.jpg` – homepage hero background and project image
- `images/cats.jpg` – original project image asset

## Preview
Open `index.html` in a browser. Use the navigation menu to visit all four pages.
